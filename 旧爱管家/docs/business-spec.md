# 奢收多 · 完整业务方案（终版）

> 版本：V3.0 ｜ 日期：2026年4月 ｜ 涵盖：完整业务链路 + 管家端（B端）+ 用户端小程序（C端）

---

## 第一部分：完整业务链路

---

### 阶段〇 · 广告触达与线索获取

客户在抖音、小红书、大众点评、地图等渠道看到奢收多广告。广告对外宣传两种回收方式：①现场竞价回收 ②寄卖竞价回收。客户点击广告进入落地页，留下手机号或微信号。系统根据客户要出的品牌、品类、预估货值自动打标签，分配给客服团队跟进。高意向线索（主动拨打电话、留言含具体品牌型号）优先分配，低意向线索进入自动化培育池（朋友圈内容+定期触达）。

系统动作：线索入CRM → 自动打标签 → 按分配规则派给客服 → 线索状态为"新建/已分配"。

---

### 阶段A · 客服跟进与邀约

客服通过微信或电话联系客户，SLA目标5分钟内首次触达。平台抓取微信聊天记录和电话录音，分析客服跟进情况，持续对客户打标签（意向度、品类偏好、价格预期、沟通特征如"价格敏感""爱对比"等）。客服在跟进中告知两种回收方式：现场竞价回收和寄卖竞价回收。了解客户地址后预约上门时间。

系统动作：线索状态流转 新建(L01) → 已分配(L02) → 跟进中(L03) → 已预约(L04)。生成预约单，填写服务方式（上门/到店/邮寄/同城闪送）、预约时间段、商品基本信息（品类/品牌/预估数量/预估价值区间）。预约单创建后生成唯一编号（RCV-YYYYMMDD-#####），触发派单引擎分配鉴定师。

派单逻辑（三层决策架构）：

- 第一层硬性过滤：客户指定需求、人身安全判断、鉴定师可调配性验证、当日接单上限（标准5单，资深6单）
- 第二层优先级判断：大单（预估≥50万）推送转化率Top 20%资深鉴定师可跨区派单；紧急单以距离为核心优先<5公里
- 第三层智能匹配评分：工作配合度25分 + 综合业绩25分 + 距离20分 + 资历15分 + 临时调配能力15分

派单后发送确认短信给客户（含鉴定师信息+预计到达时间），T-1小时发送提醒。

---

### 阶段B · 上门报价拍照与竞价

#### B1 挂签绑定 + 报价拍照

鉴定师到场，点击管家端APP"开始服务"，任务进入"服务中"。拿到客户商品后先在商品上挂签，扫签上的码与上门回收单绑定（一物一码）。按品类对应的拍照模板拍摄——包的模板、手表的模板、黄金的模板各不同。拍摄所有瑕疵点，录入商品基本信息（品牌、系列、型号、材质、颜色、成色评级、附件完整度）。此步为报价拍照，目的是定价。

拍照完成后照片绑定唯一码，时间戳锁定，实时同步客户APP和总部系统。

#### B2 推送报价组竞价

系统按品类和品牌筛选符合条件的报价师（比如5个），同时推送。报价师在后台看到商品照片和信息，各自独立出价，系统取最高价。报价师有SLA倒计时（目标≤10分钟出价）。

#### B3 客户端竞价展示（模拟竞价机制）

客户端看到竞价回收界面：全国地图上各城市商家在出价，价格从低到高排列，竞价周期约10分钟，到时间出结果。实际逻辑：真实出价来自报价组（可能3-5人），客户端展示50-100个商家在竞价，真实出价与虚拟出价混排按时间排序，最高价一定是报价师的真实出价。

#### B4 价格沟通与议价

竞价结束，鉴定师告知客户最终价格。如客户对某件商品价格有异议，鉴定师APP有议价工具，显示该商品的底价、目标价、上限价，鉴定师可在范围内微调。超出范围需提交调价审批，主管10分钟内响应。

---

### 阶段C · 鉴定环节（价格确认后进入）

客户对价格没有异议后，进入鉴定环节。

#### C1 鉴定拍照

上门鉴定师按鉴定点拍照模板（按品牌、品类不同有不同模板）拍摄鉴定图，上传到后台。

#### C2 双鉴定师并行看图鉴定

系统同时推送给A、B两个鉴定师，各自独立判定。每个鉴定师都可以给出三种结论：真、假、存疑。

判定逻辑：

- A真 + B真 → 真，正常收
- A假 + B假 → 假，不收
- A存疑 + B存疑 → 存疑
- A和B结论不一致（任意组合不一致）→ 邀请C鉴定师做终局判定
  - C判真 → 真
  - C判假 → 假
  - C判存疑 → 存疑

#### C3 护理品重拍机制

鉴定过程中发现商品被护理过（成色与报价拍照时不一致），前面的报价作废，回到B1重新拍照、重新走竞价流程。

#### C4 根据鉴定结果拆单

一个客户可能带了多个商品（比如10个包），管家端商品清单页面按状态分组展示：已确认回收、待鉴定报价、鉴定存疑、不可回收。鉴定师在"确认回收清单"页面为每件商品选择回收方式（全额/定金/寄卖），系统按回收方式自动分组生成对应订单：

- 鉴定为真 + 客户当场出售 → 全额竞价回收订单：当场签合同、当场打全款
- 鉴定为存疑 + 客户当场出售 → 定金竞价回收订单：当场打50%定金，货品寄回总部优先实物鉴定
- 真/存疑 + 客户选择寄卖 → 寄卖竞价回收订单：货品寄回总部，走寄卖流程，客户提供保留价
- 鉴定为假 → 不收：告知客户鉴定未通过，货品退还

#### C5 合同签署与资料补全

生成回收订单后，系统检测客户账户状态：是否实名认证、是否绑定收款账户。未实名→引导客户当场完成实名；未绑卡→引导绑定银行卡或支付宝。资料完整后生成电子合同，双方电子签名、时间戳存档。

按回收方式拆分合同：全额竞价回收合同、定金竞价回收合同、寄卖竞价回收合同，用户逐个签署。

防流失机制：清单发送后10分钟客户未查看→系统推送话术给鉴定师；30分钟仍未查看→升级为客服跟进任务。

---

### 路径① D · 全额竞价回收（当场成交）

客户确认价格 → 鉴定通过 → 签合同 → 鉴定师扫唯一码确认收货 → 系统自动触发打款 → 当场打全款到账 → 推送打款成功通知含明细单。

商品状态流转：回收中(1)[待签署] → [全额待申请打款] → 待完善(2) → 待入库(3) → 待调拨(4) → 待签收(5) → 已签收(6) → 待复检(7)

---

### 路径② E · 定金竞价回收

E1：当场打50%定金给客户，货品带回总部。

E2：总部签收后优先安排实物鉴定（物鉴）。

- 鉴定通过 → 商品状态进入 待申请打款(12)[订金复检成功待申请尾款] → 待打款(13) → 通知客户，结清尾款 → 商品进入 待定价(14) 走运营流程
- 鉴定不通过（假货）→ 复检失败(9) → 待退款(10)[待退回订金] → 货品退还客户，追回定金。追不了平台买单。

商品状态流转：回收中(1)[订金待申请] → 待完善(2) → 待入库(3) → 待调拨(4) → 待签收(5) → 已签收(6) → 待复检(7) → 复检成功(8)/复检失败(9)

---

### 路径③ F · 寄卖竞价回收

#### F1 邮寄到总部

鉴定师专业包装、贴唯一码标签，平台安排顺丰取件、购买全额运输保险。客户签字确认货品状态与鉴定书一致。APP实时显示物流轨迹。

#### F2 总部签收与复检

总部签收后二次鉴定，核对成色照片与实物是否一致。一致→入库确认；不一致→立即联系客户说明（货品损耗纠纷防火墙）。

复检通过 → 待定价(14)。复检失败 → 待退回(11)[回收退回审批中] → 审批通过后退回客户 → 已退回(28)。

#### F3 总部处理（每个节点同步客户）

待定价(14) → 待拍照编辑(16)（棚拍二次专业拍摄 + AI生成商品描述 + 人工审核 + 出具正式鉴定证书）→ 在库(15) → 在售(18)。

每一步推送状态给客户。等待期每日推送同款行情，上拍前3天推送提醒。客户提供保留价（自己能接受的最低价）。

#### F4 销售渠道（麦殿入驻中古优品，三种方式）

- 平台暗拍：挂在中古优品平台，买家直接下单，不公开竞价。适合标品、价格透明度高的常规款。
- 直播间明拍：中古优品直播间公开拍卖，实时竞价。适合稀缺款、高话题性单品。
- 组货开单：针对B端/同行，按品类价格段组货批量出货。走量快，适合积压库存快速回笼。

三种渠道协同：新品优先暗拍测市场价 → 未成交转直播间明拍拉热度 → 仍未消化则组货开单批量出清。每种销售动作同步通知客户。

#### F5 议价环节

最高出价低于客户保留价时，客服联系客户沟通是否愿意接受。客户同意则成交，不同意则继续挂售。

#### F6 佣金规则

按最终成交价 × 10%，最低100元，最高3000元封顶。

#### F7 打款（正向 + 逆向）

正向：货品售出 → 7天后打款给客户（扣除佣金）。商品状态：已完成(23) → 待申请打款(12)[寄卖已售出待申请打款] → 待打款(13) → 已结算(27)。

逆向：货品售出后买家发起售后退货 → 商品进入售后退回(24)，寄卖客户打款延迟，等售后结果确定后再处理。售后完成→恢复在库(15)/在售(18)重新销售。

#### F8 寄卖超时处理（60天未售出）

降价后推给客户确认是否接受新价格，或平台按一定价格买断。买断后商品归平台所有，状态进入待申请打款(12)[寄卖转回收待申请打款]。

#### F9 寄卖转回收

寄卖期间客户主动要求平台买断，或超时触发平台买断。走打款流程后商品归平台，继续在库/在售销售。

---

### 逆向流程汇总

#### 逆向1 · 现场收货后总部复检发现假货

全额回收：货品到总部复检发现假货 → 复检失败(9) → 已处理(29)。先联系客户追回货款，追得了就追，追不了平台买单。

定金回收：复检失败(9) → 待退款(10)[待退回订金] → 货品退还客户，追回定金。客户拒绝退还按合同约定处理。

寄卖：复检失败(9) → 待退回(11)[回收退回审批中] → 审批通过 → 已退回(28)。

#### 逆向2 · 客户主动反悔不卖了（全额回收已成交）

客户要求退回货品。客户把钱退给平台，平台把货品寄回客户。合同中约定反悔窗口期（如签约后24小时内可反悔）。如果货品已转售出去则无法退回。

#### 逆向3 · 寄卖期间客户要求取回货品

尚未上架或挂售中 → 直接下架寄回，收取物流+鉴定服务费。正在拍卖中（直播/暗拍有人出价中）→ 等本轮拍卖结束后才能取回。

#### 逆向4 · 买家售后退货

中古优品买家收到货后发起售后退货 → 商品进入售后退回(24)。货品退回平台，寄卖客户打款延迟，等售后处理完毕后决定重新上架还是退回寄卖客户。

#### 逆向5 · 物流损坏/丢件

货品在运输途中损坏或丢失。走运输保险理赔，平台先行赔付客户（按竞价价格或保留价）。

#### 逆向6 · 鉴定争议

客户对鉴定结果不认可。提供第三方复检通道（如中检/优奢易拍），以第三方结果为准。第三方判真 → 平台按原价收回并承担复检费用。

#### 逆向7 · 护理品发现（鉴定环节）

鉴定过程中发现商品被护理过，成色与报价拍照时不一致。前面报价作废，回到B1重新拍照重新竞价。

#### 逆向8 · 价格审批被拒

鉴定师现场调价超出权限提交审批，主管拒绝。鉴定师需按原价与客户重新沟通，或申请更高级别审批。

### 销售流程（麦殿/平台自有货品）

无论是全额回收归平台的货品、还是寄卖货品，进入销售阶段后走统一流程：

在售(18) → 待支付(19)[待支付/已支付/已完成] → 待发货(20) → 已发货(21) → 已签收(22) → 已完成(23) → 已结算(27)

特殊状态：借出(25)用于展会或三方鉴定、锁定(26)用于手动或业务锁定。

---

### 交易完结与复购

打款完成后推送完整账单截图（可直接分享）+ 再次预约入口。客户沉淀为已成交会员，记录偏好品类、成交均价、鉴定通过率。高价值客户标记专属客服跟进。主动邀请晒单，整理拍卖成功案例做小红书/朋友圈传播内容。

---

### 四大订单类型与状态对照

| 订单类型 | 触发条件 | 现场打款 | 后续打款 | 终态 |
|---------|---------|---------|---------|------|
| 全额竞价回收 | 鉴定真 + 当场出售 | 全款 | 无 | 已结算(27) |
| 定金竞价回收 | 鉴定存疑 + 当场出售 | 50%定金 | 复检通过后结尾款 | 已结算(27)或已退回(28) |
| 寄卖竞价回收 | 客户选择寄卖 | 无 | 售出后7天打款（扣佣金） | 已结算(27) |
| 假货不收 | 鉴定假 | 无 | 无 | 不生成订单 |

### 三、上门鉴定师核心操作流程

1. 接到任务 → 查看任务详情（客户信息、地址、商品品类、预估数量）
2. 点击"出发" → 客户端收到"鉴定师已出发"通知
3. 到达后点击"开始服务" → 任务进入"服务中"
4. 挂签 → 扫码绑定 → 按模板报价拍照 → 提交报价组竞价
5. 等待竞价结果（客户同步看到竞价界面）
6. 竞价结束 → 与客户沟通价格 → 如需议价使用议价工具
7. 价格确认后 → 按鉴定模板拍鉴定图 → 提交后台鉴定
8. 等待鉴定结果 → 结果回流到APP
9. 商品清单页面分组展示：已确认回收/待鉴定/鉴定存疑/不可回收
10. 为每件商品选择回收方式（全额/定金/寄卖）→ 确认回收清单
11. 系统按回收方式自动拆分生成订单
12. 引导客户补全实名+绑卡 → 生成合同 → 客户签署
13. 全额订单当场收货打款 / 定金订单收货打定金 / 寄卖订单包装邮寄
14. 完成服务 → 结束任务

### 六、实名认证

在合同签署前，系统自动检测用户是否已实名。

未实名 → 引导完成：姓名 + 身份证号输入 → 身份证正反面拍照上传（OCR自动识别）→ 人脸识别活体检测（调用系统相机）→ 认证成功后状态变为"已实名"，信息脱敏展示。

### 八、合同签署

勾选"我已阅读并同意" → 点击签署 → 弹出电子签名板 → 手指/触控笔签名 → 确认签署 → 签署成功页面。
