使用说明

本原型 shell 通过 iframe 串联 v0.3 所有真实设计稿,模拟 APP 原生体验。
底部 tabbar
点击 首页 / 我的竞拍 / 购物袋 / 我的 跳转主路由(始终可点)。
首页
· 顶部消息图标 → toast / 购物袋 → cart
· 我的中拍 → cart / 待付款·待发货 → 订单列表
· 保证金 → 保证金主页
· 明拍/暗拍板块 → 各自主页
· 热门拍卖卡(按渠道徽标分流) → 明/暗拍详情
明拍 / 暗拍
· 货品卡 → 对应详情(暗拍/明拍)
· 出价按钮 → 出价弹窗
· 代理出价/改代理 → 代理弹窗
· 规则/出价记录链 → 二级页
个人中心
· 保证金卡 → 保证金 · 优币 → toast
· 我的购买 4 列 → 订单列表
· 我的竞拍入口 → favorites
· 工具(实名/地址/反馈/客服) → 对应页 / toast
订单流
cart → 订单确认 → 收银台 → 支付结果
订单列表 → 立即支付走收银台、查看物流走物流页
回退
顶部 ← 按钮回退浏览栈;左侧 nav 不入栈,可随时切换。
